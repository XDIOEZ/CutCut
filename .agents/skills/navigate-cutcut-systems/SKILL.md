# 轻截系统总导航

## 路由工作流

1. 先读 `docs/project-memory.md`、`references/pending-boundaries.md` 和 `references/iteration-log.md`。
2. 根据下表选择一个或多个系统 Skill；跨系统任务同时使用所有相关 Skill，不把联动遗漏给后续任务。
3. 按系统 Skill 的入口、边界、联动和验证规则执行修改；过程中维护“导航候选”清单。
4. 交付前复核本次新增、删除、移动、重命名和新发现的文件，按“导航完整性维护”更新系统 Skill 与本路由。
5. 为每个实际使用的 Skill 写一条简短日志；所有迭代日志最多保留最近 10 条。

## 系统路由

| 任务范围 | 使用 Skill | 典型联动 |
| --- | --- | --- |
| 启动、设置、快捷键、软件更新页 | `$navigate-startup-settings` | 模块设置页、主窗体、持久化、发布资产 |
| 截图、选区、标注、贴图重新编辑、导出 | `$navigate-capture-editor` | 保存、OCR、长截图、录屏、模块运行时 |
| 保存、命名、路径、剪贴板、历史、通知 | `$navigate-saved-artifacts` | 截图导出、录屏产物、模块图片宿主 |
| 模块契约、发现、启停、替换、删除、热卸载 | `$navigate-module-runtime` | 所有模块、设置导航、发布包 |
| OCR、PaddleOCR、二维码、结果窗、翻译 | `$navigate-ocr-results` | 截图源、模块运行时、模型资源 |
| 长截图、采样、匹配、拼接、预览 | `$navigate-long-capture` | 截图编辑、模块生命周期、导出 |
| 屏幕录制、音视频、帮助进程、实时标注 | `$navigate-screen-recording` | 截图坐标、保存历史、模块生命周期 |
| 打包或发布正式版本 | `$publish-cutcut-release`，仅在用户当前需求明确要求时 | 版本、模块资产、网站、GitHub Release |

贴图悬浮窗属于复合系统：功能/重新编辑使用 `$navigate-capture-editor`，模块生命周期使用 `$navigate-module-runtime`，保存/复制使用 `$navigate-saved-artifacts`。无法由单个系统覆盖时不要强行单选。

## 导航完整性维护

任务中发现下列稳定信息时，立即列为导航候选：

- 遗漏的核心入口、管理器、服务、接口或数据模型。
- 重要调用方、实现类、事件发布方或订阅方。
- 与当前系统稳定依赖的脚本、资源、配置或关联系统。
- 新增、删除、移动或重命名的核心文件和目录。
- 新增的对外接口、扩展点、配置、测试或运行入口。
- 已失效、不完整或容易误导后续 AI 的导航路径。

只在候选具备长期导航价值时写入系统 Skill。新增文件满足以下任一项且职责稳定，即应补录：

- 属于系统核心职责。
- 会成为常用入口、公共接口或扩展点。
- 会影响其他系统或被多个模块调用。
- 后续执行类似任务时需要快速定位。

不要逐一登记普通实现脚本、一次性迁移、临时目录、生成文件或仅由单个实现内部使用的细节。优先记录能帮助定位系统、理解架构、判断修改面或检查联动的核心路径。

## 更新位置

- 文件或调用关系补充：更新对应系统 Skill 的“文件导航”或“联动照护”。
- 架构边界、性能要求或验证方式变化：更新对应系统 Skill 的规则与验证章节。
- 新系统、职责迁移、常见任务措辞变化或跨系统组合变化：同时更新本 Skill 的“系统路由”。
- 核心入口被删除、移动或重命名：同一任务内移除旧路径并写入新路径，禁止保留误导性兼容说明。
- 无法确认归属：不要强行写入系统 Skill；将路径、已知证据、候选归属和待补证据写入 `references/pending-boundaries.md`。获得足够调用关系或职责证据后再归类并删除待确认项。

## 完成检查

1. 对照本次变更文件和查阅到的调用链，确认导航候选均已判定。
2. 检查实际使用的系统 Skill 是否仍能从任务直接定位核心入口。
3. 检查联动系统是否需要一起更新，尤其是公共接口、配置、测试、脚本和运行入口。
4. 更新必要的系统 Skill 和总路由后，再写迭代日志。

## 迭代日志

- 总导航日志位于 `references/iteration-log.md`；格式为 `日期 | 路由任务 | 使用的系统 Skill | 路由缺口/改进`。
- 新记录追加在末尾；超过 10 条时删除最旧记录，始终只保留最近 10 条。
- 系统修改日志写入对应系统 Skill；只发生路由规则调整时仅写总导航日志。
