# 贴图悬浮窗模块

此安装包为轻截提供可独立装卸的贴图悬浮窗功能。解压后，将包内的 `Modules` 文件夹合并到
轻截程序目录；也可以直接把 `Modules\PinnedImage` 复制到程序旁的 `Modules` 中。

安装后重新开始一次截图，确认选区并完成标注，再点击工具栏中的“贴图”。当前最终选区会变成
置顶、无边框的悬浮图片，并关闭原截图编辑窗口。

- 左键拖动图片内部：移动贴图。
- 拖动四条边或四个角：默认保持原比例缩放。
- 按住 `Shift` 拖动边或角：自由改变宽高比例。
- 右键：打开“删除 / 复制 / 保存 / 编辑”菜单。
- “编辑”：关闭当前贴图，并把当前图片重新送回轻截编辑窗口。

## 在贴图上直接选择文字

同时安装并启用支持位置识别的本地 OCR、PP-OCR Tiny 或 PP-OCR Small 后，贴图右键菜单会出现
“识别文字”。只有一个可用引擎时直接识别；有多个时，在该菜单下选择识别引擎。此联动需要使用
同次更新后的主程序、贴图和 OCR 模块，旧 OCR 模块只有结果窗口能力，不会出现在可用引擎中。

识别成功后不会弹出文字结果窗口，而是在原贴图上直接操作：

- 左键按住文字并拖动：按阅读顺序选择文字，支持跨行与反向选择；蓝色半透明高亮覆盖原文字。
- `Ctrl+C` 或右键“复制文字”：复制选中内容；`Ctrl+A` 选择全部文字，`Esc` 清除当前选区。
- `Shift+左键`：从已有选择起点延伸选择。
- `Alt+左键` 拖动图片内部：移动贴图。
- `Alt` 加拖动边角：保持比例缩放；再按住 `Shift` 可自由改变宽高。
- 右键“退出文字选择”：恢复普通左键移动和边角缩放。

高亮随显示大小映射到原图位置，仅作为交互效果；菜单中的“复制”和“保存”仍处理原始图片，
不会包含蓝色高亮。无文字或识别失败时保留当前贴图及原有交互，并给出短暂提示。
关闭贴图会取消该贴图的识别请求；识别过程中停用或删除 OCR 插件时，正在执行的请求完成后才释放
识别资源。已经得到的文字位置可以继续使用，但不能再发起该引擎的新请求。

PP-OCR 请求逐字检测位置；Windows OCR 的词内字符位置按测量字宽分配。文字过小、艺术字体、
倾斜文本及 OCR 错字可能影响选中边界或复制内容，不能视为图片原始文本数据。

### 手动验收

1. 分别只启用贴图、贴图加一种 OCR、贴图加多种 OCR，检查“识别文字”的显示与引擎选择。
2. 用包含中文、英文、标点和多行文字的贴图识别，向前及反向拖选半句、整句和跨行内容，
   检查蓝色高亮，并复制到文本编辑器核对文字、空格与换行。
3. 检查全选、清除、Shift 延伸、文字靠近图片边缘的选择，以及拖出窗口再松开鼠标。
4. 按 Alt 移动与缩放贴图，在不同缩放比例和显示器上再次选字，检查高亮跟随原文。
5. 选中文字后使用原有图片“复制”和“保存”，检查最终图片没有蓝色高亮；退出文字选择后检查普通拖动。
6. 检查空白图、重复识别、识别中关闭贴图、停用/删除 OCR 或贴图模块，确认不会弹出过期结果或阻塞截图流程。

再次开始截图并完成框选后，位于截图框、工具栏等截图交互区域之外的既有贴图仍保持可操作：
可以继续拖动、缩放，也可以打开右键菜单执行复制、保存或删除，而无需先结束当前截图。
框外的 `Ctrl + 左键拖动` 仍保留为重新框选手势。

复制和保存使用贴图原始像素；仅改变悬浮窗显示大小不会重采样或覆盖原图。编辑会把贴图当前像素
作为新的编辑底图，之后可继续添加、选择和修改新元素。

模块目录：

```text
Modules/
  PinnedImage/
    ScreenshotTool.PinnedImage.dll
```

贴图模块与包含 `IModuleImageHost` 契约的主程序版本配套使用。删除整个
`Modules\PinnedImage` 文件夹即可卸载；也可以在“插件模块”页禁用或永久删除。禁用、删除或替换
模块时，模块会关闭并释放它创建的全部贴图窗口。
