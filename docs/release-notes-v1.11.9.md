# 轻截 v1.11.9

- 工作台左侧“立即截图”下方新增“打开保存目录”，启用日期分类时打开分类父目录。
- 支持同时打开多个独立截图框，默认上限为 3，可在截图设置中调整为 1～10；截图及录屏分别操作和保存。
- 截图与录屏工具栏支持拖动，当前会话保留手动调整的位置。
- 录屏实时批注支持右键编辑、删除，以及数字键选择工具和长按后恢复鼠标穿透。
- 录屏新增自定义输出分辨率、视频与音频压缩选项，录屏文件名调整为日期时间在前、类型在后。
- 图库支持拖出图片和视频供外部软件使用，也可拖入文件交给系统查看器打开；向悬浮贴图拖入图片会新建贴图。
- 为多个会话的图片保存和录屏文件名分配增加并发保护。

本次同步更新录屏模块至 1.8.0、贴图模块至 1.0.1。

提供四种整包、八个独立模块包及 SHA256SUMS.txt。轻量版需要 .NET 8 Desktop Runtime；内置运行库版可直接运行。两个完全版包含全部八个模块。

按发布要求直接生成正式资产，未运行独立逻辑测试或界面交互验收。
