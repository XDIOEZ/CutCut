# 轻截录屏模块安装说明

录屏是可选模块，默认已预装在轻截完整包中，不会包含在独立基础包中。录屏模块 1.8.0 需要轻截基础程序 1.10.0 或更高版本；
升级录屏模块时也请更新基础程序，不能只把新版模块安装到旧版主程序中。版本匹配后，将压缩包里的
`Modules\ScreenRecording` 文件夹复制到轻截程序旁的 `Modules` 文件夹，然后重新启动轻截或在托盘菜单选择“重新加载模块”。卸载时删除整个：

```text
Modules\ScreenRecording\
```

安装后，先像普通截图一样框选同一显示器内的区域，截图工具栏会出现“录屏”按钮。录制支持：

- MP4 / H.264，1、5、10、15、24、30 或 60 FPS；
- 视频码率支持 32、64、128、256、512 kbps 和 1、2、4、8、12、20 Mbps；
- 输出尺寸可跟随选区原始分辨率、指定自定义宽高，或按最长边等比缩小；自定义尺寸与选区比例不同时留黑边，不拉伸、不改变录制区域，编码尺寸自动取偶数；
- “超级压缩（极省空间）”预设使用最长边 320 像素、5 FPS、视频 64 kbps、单声道 AAC 96 kbps；预设保留系统声音/麦克风的原有开关，小字与快速运动画面会损失细节；
- 音频码率支持 96、128、160、192 kbps，可选单声道；系统声音与麦克风混成一条音轨；
- 根据视频码率和启用的音频实时估算 1 分钟、10 分钟、1 小时储存占用；
- 系统声音、麦克风，或两者混音；
- 录制从开始到结束都直接使用截图模式的同一条菜单栏，录屏模块不创建编辑按钮或专用控制窗；
- 录制中可按住工具栏左侧拖动把手、空白区或计时文字移动工具栏；暂停/继续和切换绘图工具后保留本次会话的位置。截图工具栏同样支持拖动，此能力由更新后的主程序提供；
- 模块程序集自带独立“录屏设置”页，采用纵向单列和滚动区域，统一管理画质预设、输出分辨率、视频/声音压缩和储存估算；在“插件模块”页点击录屏模块的“管理配置”后由专属窗口承载，点击“录屏”时直接采用已保存参数；
- 左键黄色半透明圆圈默认开启；开启时录制现场和最终 MP4 同步显示，按住左键期间持续跟随鼠标移动，松开后短暂保留，关闭时两处都不显示；
- 录制选区默认显示红色虚线范围提示，可在“录屏设置”中改为实线或不显示，该提示不会进入 MP4；
- 未选择编辑或绘图工具时鼠标穿透到被录制程序；录屏专属橙色“选择”按钮位于“矩形”左侧，开启后切换为高对比绿色“✓ 选择中”和白色强调边框，左键可单选、`Ctrl` 多选、框选、重叠轮选、移动和缩放元素；框选采用与截图模式一致的半透明蓝色填充与虚线边框，再次点击后恢复橙色“选择”和鼠标穿透状态；
- 全屏录屏编辑使用持久离屏画布进行局部合成，并缓存拖动期间的吸附参考，避免每次鼠标移动刷新整个透明全屏层或在清空旧位置时产生闪烁；
- 实时批注的菜单、命中、框选、`Ctrl` 多选、`Alt + 左键` 移动、普通元素八手柄缩放、箭头首尾端点缩放、`Ctrl` 固定步长拖动、元素吸附、删除和文字双击重编辑都由截图核心提供；
- 工具栏“吸附”按钮和快速双击 `Ctrl` 可切换当前会话的元素吸附；吸附距离与 `Ctrl` 拖动步长读取主程序“图片修改”设置；
- `Alt + 滚轮` 旋转、`Ctrl + 滚轮` 缩放，并支持粘贴图片或文字贴纸；
- 录制期间切换矩形、椭圆、箭头、画笔、文字和马赛克进行实时批注；
- 完成的元素可直接右键呼出“编辑”“删除”：编辑进入选择模式并自动选中该元素，可移动和缩放；选择模式下再次右键点“编辑”退出选择，恢复鼠标穿透。删除只移除右键命中的元素，菜单不进入 MP4；
- `1～6`（含数字小键盘）分别使用矩形、椭圆、箭头、画笔、文字、马赛克；`1` 左侧的 `~` 物理键切换选择，无需按 Shift。短按切换，同一工具再次短按关闭；长按至少 350 ms 或按住期间开始鼠标编辑时临时使用，松键自动提交当前绘图和文字并恢复鼠标穿透，已经画好的元素保留；提交标注不会停止录屏。鼠标需位于录制区域或工具栏，文字输入时数字仍正常输入；
- 可多次按截图快捷键创建独立截图框，再分别启动录制；“截图设置”提供同时保留的截图框上限，默认 3，可设置 1～10。各框工具栏和元素独立，后台输入由当前活动框处理；同时启动的录制分别保留输出文件名，关闭一个框不结束其他框；
- 暂停、继续、撤销、清空和停止保存；
- 保存成功后在当前屏幕右下角显示提示，点击提示会打开资源管理器并选中对应 MP4 文件。

点击“停止并保存”且视频成功生成后，本次截图会话会直接结束，不会重新显示截图框。只有取消录屏或录屏保存失败时，宿主才恢复原截图框供用户继续操作。

文件按录制开始时间命名，例如 `20261010_113340_录屏.mp4`；同名时依次使用 `20261010_113340_录屏_2.mp4`、`20261010_113340_录屏_3.mp4`。

超级压缩按目标码率估算：有声约 1.2 MB/分钟（72 MB/小时）；关闭系统声音与麦克风后约 0.48 MB/分钟（28.8 MB/小时）。还能手动选择 1 FPS 与 32 kbps，适合几乎静止的画面，静音目标约 0.24 MB/分钟；这些是码率估算，实际文件包含封装开销并随画面复杂度浮动，不是大小上限。当前系统 AAC 编码器最低支持 96 kbps，单声道不会额外减半已设定的码率；不要把音频压缩宣传为 16/32 kbps。低码率、低帧率或小输出尺寸使用系统软件 H.264 编码器，避免硬件编码器拒绝这些规格；Windows 8 及以上的低于 1 Mbps 档位使用恒定码率控制，常规档位保留原可变码率。已有配置缺少新字段时仍保持原尺寸、30 FPS、8 Mbps 和 128 kbps 立体声；保存后从下一次录屏生效。

模块与 `Modules\ScreenRecording\Recorder` 内的编码帮助进程需要一起更新，新输出尺寸和音频参数由模块传入帮助进程；不需要新增编码依赖。

录屏编码器需要 Windows Media Foundation 和 Microsoft Visual C++ x64 运行库。Windows N/KN 或
Windows Server 若缺少 Media Foundation，需要先安装相应的 Media Feature Pack / Media Foundation 功能。

录屏后端使用 MIT 许可的 ScreenRecorderLib，许可文本随模块包一同提供。

Windows 10 1903 及以上使用 Windows Graphics Capture 录制目标显示器，旧系统保留 Desktop Duplication。主屏和副屏均可录制，选区仍需完整位于同一显示器内。
